# SoulForge Physics: The Causal Bridge for Unreal AGI

SoulForge Physics is the foundational cognitive bridge for the Daithon AGI project. It connects high-level semantic reasoning with the deterministic world of Unreal Engine's physics.

## 🧠 Architecture Overview

SoulForge operates on a **Trinitarian Cognitive Model**:
- **Senku (The Skeptic)**: Rigorous causal inference and scientific validation.
- **Xeno (The Oracle)**: Chaos theory analysis and non-linear bifurcation discovery.
- **Creatus (The Architect)**: Synthesis of emergent strategies and structural design.

## 🚀 Key Components (Public Interface)

- **Causal World Model**: A Directed Acyclic Graph (DAG) system for mapping physical dependencies.
- **Experimental Validator**: Interface for double-blind physical simulations in Unreal Engine.
- **Semantic Graph (Contextus)**: Long-term persistent memory for cross-domain knowledge transfer.
- **Omni-Inject**: Dynamic logic injection into Unreal actors at runtime.

- `metacog/abstraction_engine.rs`: Multi-stage meta-reasoning logic.
